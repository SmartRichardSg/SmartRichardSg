📖 User Guide — Read Before Using ⭐ Which app should I try?
🌱 Everything here is free to use.These tools are created and shared to encourage lifelong learning and greater confidence with technology.

📱 Save the Smart Richard icon

You can save this icon to your phone or computer and use it as a reminder for your Smart Richard tools.

⬇️ Save Icon

On iPhone/iPad, if a download button does not appear, press and hold the image and choose Save to Photos. On Android, press and hold the image and choose Download image.

⭐ Not sure where to begin?

Start with one small goal. If technology feels unfamiliar, try Digital Independence Coach. If you want to train attention, try Observation Coach. If you want to improve writing or speaking, try one of the communication coaches.

I'm a 70-year-old entrepreneur with a passion for learning, discovery and trying new things.

Smart Richard is my personal journey of exploring technology, learning new skills and creating simple tools that I find useful.
